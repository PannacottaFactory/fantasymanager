# Shadow Arenas

A deep fantasy arena-league management game for the browser. You manage a stable of creatures — dragons,
trolls, goblins, elves, golems, wyverns… — recruit, train and set tactics, and a deterministic simulation
decides the fights, narrated live like a sports commentary.

**Status: phase 1** — Training Arena: build two teams, watch the fight with live commentary, make
substitutions at the breaks and read the post-match report.

```bash
npm install
npm run dev          # play in the browser
npm test             # engine unit tests
npm run sim:match    # a full match in the terminal
npm run sim:batch    # balancing statistics over many matches
```
